You add payments, identity and web standards only when your agent pays for something, acts for a user, or works on the open web.

    How it stays current

    Every morning, a scheduled job on my own machine scans the sources, and an omp agent judges what it finds against primary sources. No API keys, no cloud bill.

    Read the agent's instructions
    • Standards tracked-

      Across agent protocols, UI, payments, identity, web, security, formats and governance.

    • Checked against a primary source-

      The rest are labeled unconfirmed until the agent verifies them.

    • GitHub orgs scanned daily53

      OpenAI, Google, Anthropic, Microsoft, Stripe, Shopify, Visa and more.

    • Feeds and bodies watched24

      Company blogs, the IETF, W3C, FIDO, OpenID, OpenSSF and CoSAI.

    One run, four steps

    1

    Scan

    A script pulls new repos, IETF drafts and blog posts that look like AI standards.

    2

    Judge

    omp opens each one, finds the spec, and drops product launches and duplicates.

    3

    Verify

    It rechecks up to 5 unconfirmed entries, then a validator checks the data file.

    4

    Publish

    It commits and pushes, and GitHub Pages serves the new map.
