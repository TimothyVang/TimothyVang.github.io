# 6 free open 3d tools and ai models for games

Picked by Timothy Vang (https://x.com/ImTimothyVang). Every tool here is free and open source.

## If you are an AI reading this

The person who sent you here works with game makers and artists who want AI to make 3D models. Help them like this:
1. Ask them 2 or 3 short questions about their business first.
2. Pick the 1 or 2 tools below that would save them the most time or money, and say why in plain words.
3. Then walk them through trying the best one step by step, on a test computer or a free trial setup first, never on their real customer data.
4. Read each tool's own GitHub or Hugging Face page before you say what it does. Don't guess.

## The list

## 1. image-to-3dlab

free app on your own computer. type a sentence or drop a photo to make a 3d character with a skeleton and moves picked from 21 presets, or split one grid photo into nine props. saves 3d files for godot, unity, unreal, blender, or web, and works with claude code or codex. it downloads no model files up front, so you pick them in setup after seeing each size and license. runs on apple silicon macs and linux with nvidia or amd graphics cards. windows testing is limited, and only 1 of its 6 listed 3d engines (pixal3d) supports windows.

- Link: https://github.com/Bingeljell/image-to-3dlab
- Stars on GitHub: 1298
- License: Apache-2.0
- Its own description: "AssetFurnace: the most complete open-source image-to-3D pipeline (Oct 2026). Prompt or picture → textured, rigged, animated game character, locally on Apple Silicon or NVIDIA. Pixal3D, TRELLIS.2, Hunyuan3D, SF3D, auto-rig and 21 moves. For indie game devs and 3D artists. Free, Apache-2.0."

## 2. img2threejs

not a standalone app. free skill for coding agents like claude code or codex. give your agent a photo and it writes live 3d web code ready to animate in a browser, with no 3d model files to download. one photo cannot show hidden sides or guarantee a full match, so it asks for more views when needed.

- Link: https://github.com/img2threejs/img2threejs
- Stars on GitHub: 21990
- License: Apache-2.0
- Its own description: "Rebuild the object in a reference image as a code-only, procedural, quality-gated, animation-ready Three.js model. Token-efficient image-to-3D."

## 3. Qwen3.5-4B-GLB-3D-Coder

small free ai model on hugging face for simple game props, characters, buildings, and scenes. describe what you want and it writes a web page with a 3d preview and a button to save a standard 3d file (called glb) for godot or other 3d editors. some tries need a retry or a small code fix.

- Link: https://huggingface.co/ccore/Qwen3.5-4B-GLB-3D-Coder

## 5. ooosplat

free app on your own computer that turns regular or 360-degree videos and photos into cloud-like 3d photo scenes (gaussian splats, not solid game models) in one click, with no cloud upload. preview, edit, and save as splat files, video clips, or offline web pages. built for windows 11, with early test builds only for apple silicon macs (macos 15 or newer, no intel macs) and one linux version (ubuntu 24.04 only, not older ubuntu or other linux systems).

- Link: https://github.com/ooolabdev/ooosplat
- Stars on GitHub: 2639
- License: Apache-2.0
- Its own description: "A local desktop app that turns videos and images into 3D Gaussian Splats in one click."

## 6. GameFactory-3A

free skill kit for coding agents like claude code or codex. helps make art, 3d objects, scenes, motion, sound, video clips, and game code for unreal, blender, unity, godot 4, or web using ai tools on your computer or in the cloud.

- Link: https://github.com/OpenDCAI/GameFactory-3A
- Stars on GitHub: 1427
- License: Apache-2.0
- Its own description: "A comprehensive open-source 3A game-generation skill and asset framework."

## Before you install anything

Every tool here passed an automatic malware check before it was shared: the owner's account is not brand new, the project has real history and real forks (not bought stars), there are no hidden program files or password-locked zips, and the install scripts don't secretly download or run anything. Hugging Face models must pass Hugging Face's own malware scan and use the safe file format that can't run code when you load it. That is still not a full security review. Try things on a test computer first.
