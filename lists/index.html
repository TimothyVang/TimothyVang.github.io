How every tool is checked

Fake projects on GitHub are a real way people spread viruses. So before a tool goes on a list, a script checks it without ever downloading or running it.

This is not a full security review. Try new tools on a test computer first.

  • No fake stars✓

    Bought stars rarely come with real copies (forks). Lots of stars with almost no forks gets a tool thrown out.

  • No hidden programs✓

    No .exe or .dll files tucked inside, no password-locked zips, no "turn off your antivirus" steps.

  • Safe install steps✓

    The install scripts can't secretly download or run anything.

  • A real owner✓

    The account is not brand new and the project has real history.

  • Safe AI models✓

    Hugging Face models must pass Hugging Face's own malware scan and use the file type that can't run code when you load it.
